📐 PART 2 // 本日核心文法速記（秒殺錨點 ＆ 2 大考點） 收合/展開 ▲
⚡ 秒殺錨點：條件句三劍客：that 尾巴 vs. of 尾巴
  • 🔹 👀 看到 in the event that / provided that / given that ➔ 後面必接【完整句子 (S+V)】
  • 🔹 👀 看到 in the event of / in case of ➔ 後面必接【名詞片語 / V-ing】
  • 🏆 法則：⚡ 教練金句：字尾帶 that 接句子，字尾帶 of 接名詞！
📐 文法模組 #1：Rule 2：條件連接詞（provided that / as long as）vs. 範圍界定詞（as far as）
  • 📐 秒殺公式：✅ provided that / providing that / as long as + S + V（只要……／在……條件下） ｜ ✅ as far as + S + know / be concerned（就……範圍而言）
  • 💡 觀念解析：多益常將 provided that / as long as（表條件：只要……）與 as far as（表範圍程度：就……而言）放在同一組選項中。若句意為「只要滿足某項前提條件，即可執行某事」，必選 provided that 或 as long as；若句尾為 is concerned 或 I know，才選 as far as。
  • ✅ 正確示範：Full tuition reimbursement can be approved provided that both the department supervisor and human resources sign the authorization form. （只要部門主管與人資部雙方皆簽署授權表單，即可核准全額學費補助。）
  • ⚠️ 常見陷阱：❌ 常見陷阱：中文都翻成「只要／就……」，誤用 as far as 引導條件子句。
📐 文法模組 #2：Rule 1：疑問詞引導不定詞 (how best to) 與 介系詞關係代名詞 (介系詞 + whom / which)
  • 📐 秒殺公式：✅ S + V + [疑問副詞 how / where / when] + best to + V ｜ ✅ 先行詞 (人), 介系詞 + whom + S + V
  • 💡 觀念解析：多益 Part 5 兩大結構秒殺：(1) 疑問詞搭配不定詞片語作受詞（disagree over how best to advertise... 如何最妥善地宣傳），當及物動詞後已有名詞受詞時，絕不可選代名詞 what，必選副詞 how；(2) 介系詞後若接指人的先行詞，必用關係代名詞受格 whom（如 without whom, to whom, with whom），選 them 會造成 Comma Splice（逗號連接兩獨立子句）之嚴重文法錯誤，且 that 前絕不可有介系詞！
  • ✅ 正確示範：The board debated over how best to allocate the emergency contingency reserve, without which the overseas branch could not operate. （董事會激辯如何最妥善地分配緊急準備金，若沒有這筆資金，海外分行將無法運作。）
  • ⚠️ 常見陷阱：❌ 常見陷阱：誤選 what（what to do 只有在 do 後面缺受詞時才成立；advertise 後面已有名詞受詞，必須用 how）；先行詞為人時誤選 without that（關代 that 前方嚴禁介系詞與逗號）。
